¿Qué es un Hosting?

Es el servicio de almacenamiento que permite que tu sitio web esté disponible en Internet. Imagínalo como el "terreno" o la "casa" donde guardas todos los archivos (imágenes, código, bases de datos) de tu página.

Tipos de Hosting

  • Hosting Compartido: Varios sitios web comparten los recursos de un mismo servidor. Es económico e ideal para principiantes.
  • VPS (Servidor Virtual Privado): Un servidor físico dividido en compartimentos virtuales independientes con recursos garantizados.
  • Hosting Dedicado: Tienes un servidor físico entero para ti solo. Máximo control y potencia.
  • Cloud Hosting: Utiliza una red de servidores interconectados para alojar el sitio, lo que ofrece gran escalabilidad.

¿Qué es un Dominio?

Es el nombre único y exclusivo que se le asigna a tu sitio web para que los usuarios puedan visitarlo fácilmente (por ejemplo: www.google.com). Sin él, tendríamos que recordar direcciones IP numéricas complejas.

Ciclo de Vida de un Dominio

Un dominio pasa por varias etapas desde que se registra hasta que vuelve a estar libre:

  1. Disponible: El dominio está libre para ser registrado.
  2. Registrado: El periodo activo (usualmente de 1 a 10 años).
  3. Periodo de Gracia (Grace Period): El dominio ha caducado, pero el dueño aún puede renovarlo al precio habitual (0-45 días).
  4. Periodo de Castigo (Redemption Period): El dominio ya no funciona. Renovarlo es mucho más caro (30 días).
  5. Periodo de Eliminación (Pending Delete): Ya no se puede recuperar. Está a punto de quedar libre (5 días).
